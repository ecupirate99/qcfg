# 🏈 Saturday Scoreboard

A mobile-first college football scoreboard powered by ESPN's public scoreboard API.

## Features

- ✅ Live game scores that auto-refresh every 30 seconds
- 🏆 Real ESPN team logos and player headshots
- 📊 Offensive & Defensive statistical leaders
- 🎯 Live game situations (down, distance, possession)
- 📰 Post-game recap summaries with links to full ESPN articles
- 🔍 Team search & horizontal conference filters (SEC, Big Ten, ACC, Big 12, G5)
- 🔥 Top 25 ranked matchup highlighting
- 📱 Native pull-to-refresh gesture on mobile
- 🎨 Field-inspired dark theme optimized for game day
